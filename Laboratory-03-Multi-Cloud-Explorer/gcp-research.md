# Google Cloud Platform (GCP)

## Brief Overview

Google Cloud Platform, commonly called GCP, is a cloud computing platform provided by Google.

GCP provides services for computing, storage, databases, networking, artificial intelligence, machine learning, analytics, Kubernetes, and application development.

## Global Infrastructure

Google Cloud operates a global cloud infrastructure that includes Regions and Zones.

Organizations can deploy resources in different geographic locations to support application availability, scalability, and performance.

## Cloud Management Console

Google Cloud Console is a web-based management interface used to create, configure, monitor, and manage Google Cloud resources.

Users can use the console to manage virtual machines, storage, databases, networks, security, and other cloud services.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that can be used to run applications and workloads.

### 2. Cloud Storage

Cloud Storage provides object storage for files, backups, datasets, application data, and other information.

### 3. Google Cloud VPC

Google Cloud Virtual Private Cloud provides networking capabilities for cloud resources.

### 4. Cloud SQL

Cloud SQL is a managed relational database service.

## Three Advantages

### 1. Artificial Intelligence and Machine Learning

Google Cloud provides services and technologies that support artificial intelligence and machine learning workloads.

### 2. Kubernetes

Google Cloud provides strong Kubernetes capabilities through Google Kubernetes Engine.

### 3. Global Infrastructure

Google Cloud provides a worldwide infrastructure that supports globally distributed applications.

## Typical Enterprise Use Cases

GCP can be used for artificial intelligence, machine learning, big data analytics, Kubernetes applications, web applications, data storage, application hosting, and distributed systems.
