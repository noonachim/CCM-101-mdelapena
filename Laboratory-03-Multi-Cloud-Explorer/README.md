## Cloud Migration Analysis

**If this Linux server were migrated to the cloud, which AWS, Azure, and GCP services could host it?**

Given the server's specs of 1 CPU core, 1.9GB RAM, and 19GB disk, it could be hosted on **AWS EC2 t3.micro, Azure B1s, or GCP Compute Engine e2 micro**. These instances are suitable for lightweight workloads and can provide enough resources for a small Linux server.
