# Amazon Web Services (AWS)

## Brief Overview

Amazon Web Services, commonly known as AWS, is a cloud computing platform that provides many different cloud services. These services allow individuals, startups, organizations, and enterprises to build, deploy, store, and manage applications using cloud infrastructure.

AWS provides services for computing, storage, databases, networking, security, analytics, artificial intelligence, and application development.

## Global Infrastructure

AWS uses a global infrastructure consisting of geographic Regions and Availability Zones.

An AWS Region represents a geographic area where AWS operates its cloud infrastructure. Within Regions are Availability Zones that are designed to provide isolated infrastructure locations.

Using multiple Availability Zones can help organizations improve application availability and reliability.

## Cloud Management Console

The AWS Management Console is a web-based interface that allows users to access and manage AWS services.

Users can use the console to create and configure resources, manage virtual machines, configure storage, manage databases, monitor resources, and control security settings.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud, or Amazon EC2, provides virtual servers that organizations can use to run applications and workloads.

### 2. Amazon S3

Amazon Simple Storage Service, or Amazon S3, provides object storage. It can be used to store files, backups, application data, images, videos, and other information.

### 3. Amazon VPC

Amazon Virtual Private Cloud, or Amazon VPC, provides networking capabilities for AWS resources. It allows organizations to create isolated virtual networks.

### 4. Amazon RDS

Amazon Relational Database Service, or Amazon RDS, is a managed relational database service. It simplifies the process of setting up and managing relational databases.

## Three Advantages

### 1. Wide Range of Services

AWS provides many different services that can support various technical and business requirements.

### 2. Scalability

AWS allows organizations to increase or decrease cloud resources according to their requirements.

### 3. Global Infrastructure

AWS provides a global infrastructure that allows organizations to deploy applications and services in different geographic locations.

## Typical Enterprise Use Cases

AWS can be used for enterprise web applications, mobile applications, databases, file storage, backup and disaster recovery, data processing, application hosting, and large-scale online services.
