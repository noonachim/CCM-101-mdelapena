# Laboratory Activity 5: The Cloud Data Engineer

## Mission Overview

This laboratory activity focused on cloud data engineering and object storage. The mission involved deploying an S3-compatible object storage server using MinIO and Docker in the KillerCoda Ubuntu Playground. A storage bucket named `client-photos` was created to demonstrate how user-uploaded images can be stored outside a web server container.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using MinIO and Docker.
- Access a cloud service through a web interface using port forwarding.
- Create a storage bucket and upload an object.
- Document cloud storage operations using Markdown.
- Continue developing a professional GitHub Cloud Computing Portfolio.

## Tools Used

- KillerCoda Playground
- Ubuntu Linux
- Docker
- MinIO
- MinIO Web Console
- GitHub
- Web browser
- Markdown

## Skills Learned

- Understanding the differences among block, file, and object storage.
- Running a containerized cloud storage service with Docker.
- Using Docker environment variables to configure a service.
- Accessing a service through exposed ports.
- Creating buckets and uploading objects in MinIO.
- Documenting technical procedures using Markdown.
- Organizing evidence and laboratory outputs in a GitHub repository.
