# Cloud Provider Comparison

## Infrastructure Services Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID / Azure RBAC | Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers a very broad range of cloud services covering compute,
storage, networking, databases, security, analytics, and other
cloud workloads. Its large service portfolio makes it suitable for
many different types of organizations and applications.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

Microsoft Azure would be a strong choice for an organization that
primarily uses Microsoft products. Azure provides integration with
Microsoft technologies and services, making it easier for the
organization to connect its existing Microsoft environment to
cloud services.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for its AI and machine
learning capabilities and its Kubernetes services. Google also
developed Kubernetes, which is an important container orchestration
technology.

### 4. What similarities did you observe among the three cloud providers?

All three providers offer equivalent fundamental infrastructure
services such as compute, storage, networking, and identity and
access management. Although the service names and implementations
are different, they provide similar categories of cloud resources.
