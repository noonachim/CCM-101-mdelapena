# Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute is one of the most important cloud infrastructure
components because applications and services require processing power
to operate. Without compute resources, other resources such as
storage and networking would not be able to support a running
application by themselves.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable operating
system environment for servers and applications. It also provides
powerful command-line tools that allow cloud engineers to inspect
system resources, configure services, monitor systems, and manage
servers.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear
record of the infrastructure design and the decisions made before
deployment. Good documentation helps engineers understand the
system, identify potential problems, and maintain the infrastructure
more effectively.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using commands such as
`lscpu`, `free -h`, `df -h`, `mount`, and `hostname -I`. I also
learned more about the relationship between compute, storage,
networking, and operating systems in cloud infrastructure.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized because I added a
structured laboratory folder containing technical documentation,
server investigation results, cloud provider comparisons, and a
cloud architecture diagram. This makes the portfolio a better
record of the cloud computing skills and activities I have completed.
