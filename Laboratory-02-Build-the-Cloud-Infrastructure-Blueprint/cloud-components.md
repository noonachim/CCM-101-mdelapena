# Cloud Infrastructure Components

## Compute Resources

### Purpose

Compute resources provide the processing power needed to run
applications, services, commands, and other workloads.

### Importance in Cloud Computing

Compute resources are essential because cloud applications need
processing power to execute workloads. Cloud providers allow
organizations to provision compute resources according to their
requirements.

### KillerCoda Environment

In the KillerCoda Linux environment, the CPU serves as the compute
resource. It executes Linux commands and processes running on the
server.

---

## Storage Resources

### Purpose

Storage resources provide space for storing operating system files,
applications, configurations, and user data.

### Importance in Cloud Computing

Cloud storage allows organizations to store and retrieve data
without maintaining physical storage infrastructure themselves.

### KillerCoda Environment

The Linux server provides disk storage that can be inspected using
commands such as `df -h` and `mount`.

---

## Networking Resources

### Purpose

Networking resources allow computers, servers, applications, and
users to communicate with each other.

### Importance in Cloud Computing

Networking connects cloud resources and allows users and applications
to access cloud services.

### KillerCoda Environment

The KillerCoda Linux server has networking capabilities and an IP
address that can be identified using `hostname -I`.

---

## Operating System

### Purpose

The operating system manages the computer's hardware and provides
the environment in which applications and commands run.

### Importance in Cloud Computing

Operating systems provide the software environment needed to run
applications, services, virtual machines, and other workloads.

### KillerCoda Environment

The KillerCoda environment uses Linux as its operating system.
Linux provides the command-line environment used to investigate
the cloud server.
