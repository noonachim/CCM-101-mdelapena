# Laboratory Activity 2: Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focused on examining the different components of cloud infrastructure as part of CloudNova Technologies' first project. The mission involved exploring a Linux server environment to understand how compute, storage, networking, and other infrastructure services work together. The findings were documented as technical information that could help a client prepare for migrating their services to the cloud.

## Objectives

- Understand the main components of cloud infrastructure
- Examine the hardware and software resources available in a Linux environment
- Distinguish between compute, storage, networking, and identity resources
- Understand how different cloud infrastructure components work together
- Create organized technical documentation using Markdown
- Improve and maintain a structured GitHub Cloud Computing Portfolio

## Cloud Infrastructure Components

- **Compute Resources** — Provide the processing power needed to run applications and services
- **Storage Resources** — Store data, files, and other information for future use
- **Networking Resources** — Enable communication and connections between different systems
- **Operating System** — Manages hardware resources and provides a platform for running applications

## Skills Learned

Through this activity, I learned how to examine the infrastructure information of a Linux server and identify different cloud infrastructure components. I also learned how to compare the services provided by AWS, Azure, and GCP and create a basic cloud architecture diagram. In addition, I improved my skills in organizing and documenting technical information using Markdown and GitHub.

## Challenges Encountered

One challenge I experienced was understanding how compute, storage, and networking components work together within a Linux environment. I also found it challenging to compare AWS, Azure, and GCP because each cloud provider uses different names for services that perform similar functions.
