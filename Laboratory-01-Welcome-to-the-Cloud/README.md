# Laboratory Activity 1: Welcome to the Cloud

## Mission Overview
This laboratory activity introduced the onboarding process for a Junior Cloud
Infrastructure Engineer Trainee at CloudNova Technologies. The mission focused
on learning to work inside a Linux environment, documenting technical work,
and building a version-controlled portfolio using GitHub.

## Objectives
- Access a cloud-based Linux environment using KillerCoda
- Explore and navigate the Linux operating system
- Gather basic system information
- Organize files and directories using Linux commands
- Create and maintain a professional GitHub repository
- Document technical work using Markdown

## Activities Performed
- Checkpoint 1: Created a new Linux user (ccastillo) with sudo access and
  logged in to verify the environment.
- Checkpoint 2: Investigated the Linux environment and recorded the
  distribution, kernel version, CPU info, memory, and disk space.
- Checkpoint 3: Created the Documents, Notes, Report, and Screenshots folders
  in the home directory, and created about-me.md inside Notes.
- Checkpoint 4: Created the public GitHub repository CCM101-ccastillo and
  built the required folder/file structure.
- Checkpoint 5: Documented the mission in this README.md file.
- Checkpoint 6: Captured and organized screenshots as evidence.
- Checkpoint 7: Reviewed, committed, and pushed the final repository.

## Linux Commands Used
`adduser`, `usermod`, `su`, `whoami`, `pwd`, `hostname`, `lsb_release`,
`uname`, `lscpu`, `free`, `df`, `mkdir`, `ls`, `nano`, `cat`, `git`

## Skills Learned
Through this activity, I learned how to navigate a Linux environment, gather
system information, organize a file structure, and set up a professional
GitHub repository to document technical work using Markdown.
